# Overwatch Custom Mode

Кастомный режим для Overwatch Workshop.

## Структура проекта

```
├── main.ow              # Полная сборка всех правил (копировать в игру)
├── heroes/              # Правила для отдельных героев
│   └── mauga.ow         # Мауга — скорость, кастомная ульта
├── map/                 # Правила карты и спавна
│   └── spawn.ow         # Телепорт из спавна
└── README.md
```

## Герои

### Мауга

| Механика | Описание |
|----------|----------|
| Базовая скорость | 90% от стандартной |
| Скорость при Shift (Ability 1) | 120% |
| Зарядка ульты | Кастомная, заряжается за 30 секунд |
| Ульт — бросок | Импульс вперёд (сила 25) при активации ульты |

**Переменные игрока (Мауга):**
- `Event Player.N` — состояние ульты (0 = не активна, 1 = активна)
- `Event Player.X` — текущий заряд ульты (0–100)

## Карта / Спавн

- Игроки Team 1 автоматически телепортируются из спавна на случайную позицию из `Global.X`
- Телепорт повторяется каждые 5 секунд, пока игрок в спавне

**Глобальные переменные:**
- `Global.X` — массив позиций для телепорта

## Как импортировать в игру

1. Откройте Overwatch 2 → Кастомная игра → Настройки → Workshop
2. Скопируйте содержимое файла `main.ow`
3. Вставьте в редактор Workshop
4. Сохраните и запустите

## Как добавить нового героя

1. Создайте файл `heroes/<имя_героя>.ow`
2. Напишите правила для героя
3. Добавьте правила в `main.ow` в соответствующую секцию
4. Обновите этот README

## Переменные

### Глобальные
| Переменная | Назначение |
|------------|-----------|
| `Global.X` | Массив точек телепорта |

### Игрока (Per Player)
| Переменная | Герой | Назначение |
|------------|-------|-----------|
| `Event Player.N` | Мауга | Состояние ульты (0/1) |
| `Event Player.X` | Мауга | Заряд ульты (0–100) |
