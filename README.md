# Overwatch Custom Mode

Кастомный режим для Overwatch Workshop.

## Игровой режим

| Параметр | Значение |
|----------|----------|
| Длительность раунда | 5 минут |
| Команда 1 (синяя) | только Мауга |
| Команда 2 (красная) | все, кроме Мауги |
| Цели | Нет |
| По окончании раунда | Автоперезапуск |

## Структура проекта

Все правила в одном файле:

```
├── main.ow       # Полная сборка всех правил (копировать в игру)
└── README.md
```

## Герои

### Мауга (Team 1)

| Механика | Описание |
|----------|----------|
| Стрельба | Заблокирована (Primary/Secondary Fire) |
| Базовая скорость | 80% |
| Скорость при Shift (Ability 1) | 120% |
| Шифт-стан | Враг в радиусе 5м со статусом Stunned убивается |
| Мили (V) | Урон 150 в радиусе 3м, КД 0.7 сек |
| E (Ability 2) | Бросок вперёд → купол радиус 10м на 8 сек, ловит врагов |
| Ультимейт | Сфера перед Маугой, 50 попаданий → 500 урона в радиусе 8м |
| Ульта во время E | Заблокирована (N != 0) |
| Зарядка ульты | Авто, 5 секунд (1% / 0.05 сек) |
| КД абилок | Не более 5 секунд |

**Переменные игрока (Мауга):**
- `Event Player.N` — состояние: 0 = idle, 1 = бросок E, 2 = купол, 4 = ультимейт
- `Event Player.Z` — флаг Shift активен
- `Event Player.M` — кэшируемая цель (мили / шифт-стан)
- `Event Player.L` — массив пойманных в купол врагов
- `Event Player.E` — entity купола (ring effect)
- `Event Player.T` — таймер купола (8 → 0)
- `Event Player.I` — индекс цикла
- `Event Player.S` — позиция сферы ульты
- `Event Player.F` — entity сферы ульты
- `Event Player.G` — флаг "сфера активна"
- `Event Player.C` — счётчик попаданий по сфере (0–50)
- `Event Player.Y` — проекция взгляда на сферу

## Игровой цикл

- При старте матча таймер ставится на паузу
- Когда игра начинается (`Is Game In Progress`), таймер запускается на 300 секунд (5 минут)
- Когда время истекает — показывается сообщение "РАУНД ОКОНЧЕН!" и через 3 секунды матч перезапускается
- Стандартные условия завершения матча отключены (`Disable Built-In Game Mode Completion`)

## Карта / Спавн

- Игроки Team 1 автоматически телепортируются из спавна на случайную позицию из `Global.X`
- Телепорт повторяется каждые 5 секунд, пока игрок в спавне

**Глобальные переменные:**
- `Global.X` — массив позиций для телепорта
- `Global.H` — массив героев для Team 2 (все, кроме Мауги)
- `Global.I` — индекс цикла

## Как импортировать в игру

1. Откройте Overwatch 2 → Кастомная игра → Настройки → Workshop
2. Скопируйте содержимое файла `main.ow`
3. Вставьте в редактор Workshop
4. Сохраните и запустите
